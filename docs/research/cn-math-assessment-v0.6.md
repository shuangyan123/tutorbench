## 可复核的变化

- 学业质量表保留三级。一级增加用函数性质解释变化、用有限样本空间计算的具体表现；二级列出用导数分析变化和用分布解释现象；三级写入建构知识体系、引领合作和独立判断。旧第 79 页以二级为高考要求和依据，新第 75 页改用命题水平上限表述。两处均无年份或卷型。
- 附录二对水平一、二的引用从旧 20–35 变为新 20–31。逐一核对引用范围内的 16 个旧标题、12 个新标题；新标题均能找到同名旧项。旧“传令兵”“鞋号”“影子”“迭代计算”在新引用范围内无同名项。三级的新 24、26、28 与旧 25、28、31 的标题分别对应覆盖、体重与脉搏、圆柱截面。离线报告列出各自起页。题干、公式、图示及解法是否等价仍待逐例对照；三组引用的语义状态均保留未决。
- 评价建议明确区分单元测验和期中期末测验，建模评价明确了求解及检验环节，结果分析提出合理使用人工智能。考试建议单列考试范围、形式、难度结构及分析报告。候选第 84 页的解答题分值至少 40% 专指学业水平考试。命题蓝图是制订蓝图的建议；本次取得的具体高考试卷蓝图数为 0。
- 另外三项未决分别是旧学业质量章末的转引列表、旧考试说明对知识技能层次的枚举，以及旧“会学数学”与新问题设计的关系。前两项仅有旧侧定位。五个新增项仅有新侧定位。未从文字缺席推导正式废止。

## 能力与图谱的证据边界

案例图式抽查定位到旧案例 31 印刷 163 / PDF 171、新案例 28 印刷 152 / PDF 155。圆柱水面的五幅示意和双球相切辅助图，图号由 31、32 变为 27、28；可见的线段关系用于椭圆截面的论证。此次抽查只确认这些图式与论证上下文，完整示例的措辞和评价语义仍待核。

作者的候选映射设计以既有概念 ID 表示“涉及什么”，以版本化的水平行定位“要求怎样表现”，并保留具体情境。例如新表一级涉及函数概念，要求从对应关系理解函数、用单调性作解释；二级在函数背景中涉及导数操作、定性定量表征、数学语言和建模。流程中的运算、表征、论证、情境建模可能共用一个知识对象。仅凭学生答出一个函数题，无法从该行获得其整级表现的证据。本阶段把水平行和建议的类型留在研究清单；尚无独立审核的具体题目证据可支撑新增图谱关系。

## 离线重放

使用 Node 24，在首次检出后运行 `npm ci` 和 `npm run build`。

在仓库根目录执行 `npm run exam:inspect -- --requirements --edition-diff assessment-guidance`。报告通过 0.5.0 读取历史来源和实施状态，为每项决定列出两侧版次、页码、类型、依据及审核状态。仅传 `--edition-diff` 仍重放集合与逻辑两小节。现有清单的 36 个要求、12 个候选关联、24 个未映射和 44+2 个图节点沿用原版本。
