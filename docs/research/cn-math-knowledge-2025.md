# 高中数学知识范围与版本差异（2025 候选正文）

本报告回答两个问题：课程让学生接触什么数学，以及图谱目前能把哪些对象说清楚。定位单位是课程主题、单元和有辨别力的条文。以下是课程内容的分层索引和定点对读，尚无逐条核准的全书知识清单。题目如何提高操作和证明要求，见[九题对照](real-exam-assessment-demands.md)。

### 离线复查示例

可用 PDF 阅读器按上表直接并排查看原页。以下示例另核对三个动词差异的页内文字，第三组锚定编号条文，避免匹配到导语。使用已有 Python PDFium 环境，将代码保存到本地后，从仓库根运行，依次传入两份 PDF 路径。匹配成功只说明指定字节和位置存在这些文字。

```python
from hashlib import sha256
import json
from pathlib import Path
import sys
import pypdfium2 as pdf

registry = json.loads(Path("src/research/data/cn-math-revision-v1.json").read_text("utf8"))
checks = [
    (26, 25, "理解平面向量基本定理", "掌握平面向量基本定理"),
    (42, 41, "了解空间向量基本定理", "掌握空间向量基本定理"),
    (47, 46, "通过具体实例,了解伯努利试验", "通过具体实例,理解伯努利试验"),
]
for edition, filename, offset, column in zip(
    ("oldSource", "newSource"), sys.argv[1:3], (8, 3), (0, 1), strict=True
):
    path = Path(filename)
    assert sha256(path.read_bytes()).hexdigest() == registry[edition]["sha256"]
    doc = pdf.PdfDocument(path)
    for row in checks:
        page = doc[row[column] + offset - 1]
        text = "".join(page.get_textpage().get_text_bounded().split()).replace("，", ",")
        assert row[2 + column] in text, (edition, row[column])
    print(edition, len(checks), "page anchors matched")
```

## 最小增量提案

1. **可复用且应分开。** 平面基要求两向量不共线，空间基要求三向量不共面。两个节点共享线性组合思想，但当前内容支持各自的维数条件。未发现支持合并它们的证据。导数作为变化率、求导运算、全域优化也应分别保留。
2. **缺少直接概念。** 优先审议一般集合的包含与相等。课标集合节和 Q19 同时需要它，量词、奇偶性、事件运算均不能单独表达任意集合包含。建议后续定义包含、相等与双向包含，并以反例和跨题样本检验边界。本次保留局部 unmapped。
3. **粒度待细化。** 二项式定理与二项分布共享系数但一个证明恒等式、一个求概率。现有计数/概率节点能记录部分基础；待有任务验证展开与系数提取再决定是否独立建点。列联表检验与一般推断、选修 A 定积分与一般极限也保留部分覆盖。选修中的名称不直接触发批量建点。
4. **任务层足够。** 建模检验、换图表、给出可行性证书和释放前问约束，可以用现有字段表达。两份报告均为作者提出的研究解释，本轮新增节点为零。
