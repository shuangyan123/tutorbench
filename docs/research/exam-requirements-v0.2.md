## Offline inspection and version control

From the repository root on Node 24, run `npm run build`, then `npm run exam:inspect -- --requirements`. The existing no-flag source inspector/diff is unchanged. To compare inventories: `npm run exam:inspect -- --requirements BEFORE.json AFTER.json`. With the same file twice both change lists are empty. No network, generated scores or model calls.

Within the existing exam-specifications directory, the requirements snapshot adds leaf annotations. The v1 scope manifest owns the independently transcribed **set of expected official anchors**, edition fingerprints, exclusions and applicability; it is not inferred from the rows or their alignments. The base parser resolves the archived registry; the graph parser validates candidate IDs. Source-section ID plus anchor is a stable requirement ID; source edition and digest accompany every resolved link. A group is a parent, never a countable leaf. Missing/duplicate/foreign leaves, changed base editions and self-declared approvals fail closed. For a partial census only observed counts are usable; even if all observed requirements have links, percentage and denominator remain null.

The report gives one census per source section and separate per-exam views. Whole-subject views always have unknown denominators. The country-level Chinese historical curriculum section is not added to the province/year paper numerator. Explicit omissions of known external leaves are counted separately from unenumerated populations. Pending review counts candidate links plus leaves awaiting evidence; explicitly unmapped means no link proposed, not a failed review. No independent review receipts exist or can be self-asserted in this version. A bounded zero reviewed percentage is not evidence of poor performance.

**Updates:** retain old snapshot, manifests, regression pins and reader at the historical commit. Add a new edition/manifest for changed source bytes, applicability, or unit boundaries; never edit a historical scope to make a rate rise. Retain stable IDs only for unchanged units. Diff the emitted source editions, scopes and leaves, reconcile splits/merges manually, and obtain an ordinary reviewed PR. No external monitoring deployed. Retain bibliographic metadata, hashes, labels and original short paraphrases only; a publisher hash is not permission to redistribute a PDF. For graduate math the digest is of the catalogue HTML, **not** of the unavailable outline. Publishers may withdraw files.
