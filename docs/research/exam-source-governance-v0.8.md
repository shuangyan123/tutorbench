# 考试规范来源治理 0.8.0

使用 Node 24 构建后，运行 `npm run exam:inspect -- --requirements --source-governance`。该命令离线解析原有来源登记、0.7.0 清单和历史候选版记录，按版次连接五条来源治理记录。每项证据含类型、位置与段落或页码。公开证据可登记 HTTPS 地址，受控记录可使用 `urn:sha256:` 定位。未收录治理元数据的其他版次继续使用原清单。此阶段没有新增要求。

| 要回答的问题 | 可核查的证据与登记边界 |
|---|---|
| 谁发行、依据何在 | 发行者、文号或版次，以及具体决议、发行通知或已发行文本。中国本例由教材局访谈和地方教育机关引用文号相互印证。保留各自所支持的事实。 |
| 核读的哪份附件来自何处 | 发行者直接下载需匹配已核实的发行者附件位置和字节指纹。公开镜像、学校转载、学校受控收文各有自己的渠道。两处镜像的 SHA-256 相同只能识别相同字节。不同摘要需进一步查版次、排版或封装。 |
| 文件核到了什么程度 | 保存实际 SHA-256、已知字节数、页数及核读区间。整份完整或缺页需要记录与预期正式页序、目录、附录等对照的核查依据。五条记录的全本完整性均保留 unknown。 |
| 可以怎样取得和使用 | 分别记录访问渠道、项目允许保存的材料和全文再用依据。本批只保存元数据、定位与自撰释义。全文许可或限制需要可定位的权利文件，公开可读和发行身份均不足以授权再发布。 |
| 对谁、从何时适用 | 地区、轨道、学科、起止日期、教学届次、教材启用、考试类型、考期、地区卷型、过渡文件均独立登记。已知值指向本来源记录内的证据。教学过渡需要实施条文，特定考期需要年度文件或明确过渡条文。 |
| 谁核过内容 | 限定小节清点、作者提出的语义关联和独立学科审核沿用现有离线报告。标准、州课程和年度重点可以有规范条目；示例与实考试题仅可作为题目证据。文件认证不改变映射状态。 |

## 学校受控下发

经授权的学校或教育机构收文可以建立文件来源链。取得及检查前先核实该渠道和拟议用途获得许可。核对发行机关和文号、授权下发依据、注明日期的机构收文记录、附件题名与版次、页数及所收附件的整文件摘要。保存可供获授权复核者查验的脱敏证据引用。校内原件、个人姓名、访问凭据和受限文件路径均留在登记表之外。仅有收件人口述时，逐页一致性和所传字节仍待确认。

`controlled-distribution` 的离线校验将上述已核查事实与具体附件绑定，登记为 `corroborated-distribution-copy`。授权、收文和用途依据使用独立字段引用已检查的记录。哈希是复核入口，录入前仍需核查底层证据。发行机构可以通过行政链分发正文，无须额外提供公开 PDF。测试中的收文记录完全为合成数据。

## 本版五条记录

- **中国，普通高中数学 2025 年修订版。** 教材局访谈支持 2025 年 10 月印发，无锡市文件支持教材〔2025〕1号文号。学校有公开转载页，既有核验未取得其附件字节。本项目实际核读的是 CDN 的 171 页候选文件，9,959,570 字节，SHA-256 为 `f520c1645c88819af0b190192e4b2fc49bbba7da156a82f04adec56c6131c3e1`。其与正式下发附件之间仍缺授权传递链。入学届次、教材启用、首个高考年份、地区卷型和过渡文件均为 unknown。13 条历史要求和 43 个候选评价单元的跨版判断继续为暂定。[访谈](https://www.pep.com.cn/rjdt/mtbd/202603/t20260330_2005956.shtml) · [无锡市文件](https://www.wuxi.gov.cn/doc/2026/04/10/4758325.shtml) · [两节对照](cn-math-revision-v0.5.md) · [评价单元对照](cn-math-assessment-v0.6.md)
- **德国，KMK、NRW 州课程、NRW 2027 年度文件。** 三个发行者渠道分别匹配各自版次和既有字节指纹。KMK 2012 决议规定共同标准，各州以自己的规定实施，IQB 示例说明任务设计。NRW 2023 州课程第 5 页明确逐级实施。NRW 2027 文件 I 明确引用州课程第 2 章，指定考期仅属于该州相应高中轨道的集中笔试。条款之间的 17 条对应关系继续由作者提出。年度重点、示例任务、实际试卷各自保留用途。[KMK 实施说明](https://www.kmk.org/bildungsministerkonferenz/bildungsthemen/bildungsstandards.html) · [NRW 州课程](https://lehrplannavigator.nrw.de/system/files/media/document/file/gost_klp_m_2023_06_07.pdf) · [2027 年度文件](https://www.standardsicherung.schulministerium.nrw.de/system/files/media/document/file/mathematik_2027_gg.pdf)
- **美国，College Board 数字 SAT。** 第 4 版由考试机构发布，表 16、21 和附录 B 表 A35 的 SAT 栏支持相应考查范围。框架的适用对象为 SAT，学校课程、AP Calculus 和大学招生政策各需自己的依据。具体首次及末次适用场次未知。[College Board 官方框架](https://satsuite.collegeboard.org/media/pdf/assessment-framework-for-digital-sat-suite.pdf)
