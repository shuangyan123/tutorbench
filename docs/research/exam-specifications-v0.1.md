## Offline reproduction and future updates

From the repo root with Node 24: `npm ci`, `npm run build`, `npm run exam:inspect`. This resolves JSON → legacy parsers → edition/locator → concept and emits a JSON trace. `npm run exam:inspect -- BEFORE.json AFTER.json` reports added/removed keys and changed SHA-256 bytes in sorted order. No changes yields `[]`; metadata-only changes are not file-byte changes. The test constructs a fixed synthetic second edition, retains the old edition and replays the comparison without network or model access. Offline integrity detects stale pins; it cannot certify a publisher's prose or a mapping.

For intake, identify the issuing authority, publication and precise paper, jurisdiction and applicability separately. Open the actual document, inspect the passage and its surrounding scope, record printed/PDF page or section and clause, and hash the complete *unmodified* response body (not extracted text, URL or a generated summary). During this pass the HTML was 9,653 bytes, KMK PDF 1,632,984 bytes and AP PDF 7,997,796 bytes. Retain only links, hashes, bibliographic metadata and short original paraphrases here; no implied redistribution rights. Changed bytes (including HTML chrome), inaccessible editions or uncertain terms trigger manual review, not a silent replacement or semantic change. Git preserves registry metadata, not third-party bytes; publishers may replace or withdraw them.

**Design only — no scheduled job installed:** daily check permitted publisher announcement feeds; weekly compare approved source hashes using conditional requests, bounded response sizes, rate limits/backoff and publisher robots/terms. Before enabling any fetching, review licensing, approved hosts/redirects, private-network exclusion, timeouts and access policy. Skip disallowed endpoints; never bypass access controls. Stage candidates as pending, review changed clauses/editions and applicability with a human, and propose an ordinary PR retaining old versions. Only a separate independent review can promote semantic alignment; byte changes never trigger scoring or automatic coverage promotion.
