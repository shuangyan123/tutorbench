# 真题与数学知识图谱的对齐试点 1.0.0

9 道题中，9 道可定位到已有概念，7 道有直接对应的中国课标条款，另 2 道只有支持性条款。现有 Correctness Verifier 确认 2 道整题答案及另 1 道的第一问。这个差距来自三种不同的证据门槛：看得到题目、能解释题目用到的知识、能在有界规则内核验答案。

## 取样与证据链

从本地 release-v2 的 667 道索引题按考试、年份、学科、卷别和印刷题号查询。8/9 来自 2026 全国Ⅰ卷。2025 全国Ⅰ卷第 14 题提供了不同于有限停止试验的占位期望结构，还能与原有双路径精确检查交叉核对。分母仅为这 9 道目的性选题。六类结构分别为导数与最值 2、解析几何 2、概率建模 2、数列与组合 1、空间几何 1、函数与集合 1。

[冻结清单](../../fixtures/research/real-exam-alignment-v1.json)逐题保留题库 ID、版本、页号、截图位置（物理页左上原点，单位 pt）、PDF/截图及答案记录摘要。每条候选关联附角色或理由，题目归属依据是题库文件和印刷题号。课标条款引用可通过 1.1.0 检查器的 `source_edition`、`locator`、`source_sha256` 复核。2026 年 8 题的题页和带题号的答案页位于同一份用户提供的 PDF，2025 年补充题的题卷与答案卷摘要不同。9/9 的配对状态均为 `matched / user_supplied_assumed_correct`。原图、完整推导、Verifier 输入及输出保存在私有目录。

## 对齐、缺口与诊断

样本触及 392 条清单中的 17 个不同条款、98 节点扩展图中的 19 个不同概念。9/9 至少有一个节点，整题完全无节点的为 0/9；同一题仍可含局部未映射需求。原有 44 节点图和 16 个考试 profile 保持独立。独立专家审核数为 0。没有学生作答，映射准确率、学生知识状态及学习效果均未知。

| 缺口 | 涉及题数 / 9 | 处置 |
| --- | --- | --- |
| 缺概念 | 1/9 | Q19 要求证明有方向的集合包含；奇性或单调性只解释函数部分。将包含关系保留为局部 unmapped。一个可供下一版审议的最小候选是“集合包含与相等”，依据为本题及已有 `cn-sets-2020/2`。本版新增节点 0。 |
| 条款只支持部分步骤 | 3/9 | Q06 的局部极值条款不足以覆盖全域指数商优化；Q17 与 2025 Q14 缺直接覆盖目标的中国选择性必修概率条款，仅列支持性条款。 |
| 表示、操作或策略 | 3/9 | Q07 的多重集配对证书、Q15 虚线图到坐标的转换、Q18 不同小问间约束的释放保存在任务层。 |
| 来源或转写证据 | 7/9 | 七道仍有未完成的题库结构化转写，本次查对了截图。多页题及答案以逐区域摘要保留。两道已有视觉转写的题也保留原来源状态。 |

类别可重叠。可观察错误指“如果一份书面解答出现此步，可以核查什么”。例如 Q17 的末项若多乘一次命中率，可直接用概率和检查；只看一个错误数值无法区分漏计、错算或转抄。Q18 中沿用前一问的特定斜率，会改变优化的可行域；简短答案不能证明学生缺少椭圆概念。

## 重放

仓库根目录、Node 24、Python 3 环境下运行。第一组只使用公开清单和既有 1.1.0 离线输出。

```sh
npm run build
python -B scripts/research/inspect_real_exam_alignment.py
python -B -m unittest scripts/research/test_real_exam_alignment.py -v
```

私有模式沿用[题库 reader](local-exam-bank-2022-2026.md)与[Correctness Verifier 环境](private-exam-correctness.md)。传入现有 release-v2 的 bank.json 和本次受限交接目录；其中 plan.json、refs.json、derivations.json 分别是选定样本的源绑定计划、参考转写及作者推导。旧试点中用于 Q07、Q19 第一问和 2025 Q14 的计划按题号复用，其他六题留空检查。每次重放重新核对文件字节，再从盲算生成结果并比较冻结状态。公开检查的 `privateEvidenceReplayed` 为 false。

```sh
python -B scripts/research/inspect_real_exam_alignment.py --bank "<release-v2>/bank.json" --private data/private/issue421
```
