# Spectrum — Teachometry homepage prototype

Design prototype for the Teachometry website overhaul (direction A, "Spectrum / 分光").
It is a standalone static page. It is **not** part of `npm run website:build`, is not
deployed by the Pages workflow, and does not replace any live route.

Open it with any static server from this folder:

```bash
cd website/prototypes/spectrum && python3 -m http.server 8770
# http://localhost:8770/?lang=zh   (or ?lang=en, add &motion=reduce to preview reduced motion)
```

Edition: light "research journal" in a periwinkle palette (reference: Noomo Agency). The
first screen is a real two-mirror kaleidoscope rendered in Blender (Cycles): mirrors at 30°
over a chamber of cathedral and dichroic glass, millefiori slices, cut crystal and air bubbles
in oil (`render/mandala.py`, palette "cool", seed 3). It opens on a still rosette inside a glass
eyepiece rim that floats on the page light; scrolling plays `K_000`–`K_119` (1400×1400, alpha
outside the eyepiece), turning the chamber by 15° so the pattern re-forms. The view never spins
and nothing moves on its own. Each frame renders a single wedge without mirrors (`WEDGE=1`), and
`render/fold.py` mirrors it into the rosette; two flat mirrors through the eye reflect exactly
across their lines, so this matches the full mirror render at a fraction of the cost
(`render/render_k.sh`, then `render/to_webp_k.py`). `cover.js` decodes each frame before using
it (every 4th frame first, then every 2nd, then the rest), eases towards the scroll position and
blends neighbouring frames. Near the end of the cover the masthead slides up over it as a sheet.
The earlier three-mirror end-cap sequences (`R_*`, `Q_*`, `P_*`, `L_*`, `render/scene.py`) are
kept but not shown. Dimension markers are five Blender glass beads (`assets/beads/`,
`render/beads.py`) instead of flat colour bars. Two GPT photographs open §2 and §3 as framed
plates, captioned as generated illustrations.
Display headings are set in Cormorant Garamond (OFL; chosen over Bodoni Moda and Instrument
Serif as free alternatives to Kessler, which needs a commercial licence). `#bodoni` /
`#instrument` (or `?serif=`) switch the face for comparison; `?display=grotesk` sets Geist.
Everything after it is laid out as one journal issue: masthead and
contents, running heads, margin notes, figures (Fig. 1–3), booktabs tables (Table 1–3),
a pull quote, notes and references, and a colophon.

- `index.html` — page structure, bilingual copy (paired `.en` / `.zh` spans).
- `spectrum.css` — design tokens (paper, ink, five spectral bands), journal grid and components.
- `cover.js` — plays the rendered cover frames (`assets/cover/`, WebP, 1920×1200) on a 2D
  canvas, decoded first and blended between neighbours. Reduced motion holds the opening still.
- `signature.js` — the brand's one repeatable visual rule, the **spectral signature**: every case is
  drawn as a line spectrum over TutorBench's 27 capability tags, grouped into the five dimensions
  (official order and mapping from `src/contracts/tutor-eval-taxonomy.ts` and
  `src/audits/rubric-authoring-qa.ts`). A line is lit for each capability the case is built to
  measure. Used on every plate card and in Fig. 4 (all 24 situations plus the summed spectrum of
  all 48 cases). It describes the case, never a score.
- `spectrum.js` — language switch, bar, sticky-figure dispersion chapter, plates shelf, Fig. 4 atlas, reveals.
- `specimens.js` — generated by `tools/build-specimens.py` from `website/dist/public-data/cases.json`
  (`tutor-eval-v0.2a@0.2a.6`): public case inputs only, no responses or scores.
- `assets/atmos.webp` — the page's light: soft peach, lavender and white glows bleeding into the
  periwinkle, fixed behind the issue (`tools/build-atmos.py`).
- `assets/` — byte-for-byte copies of the approved TutorBench T1 mark, plus two key
  visuals (`tabs-*`, `bench-*`, wide and tall crops, WebP) and the cover frames.

Boundaries kept: no model scores, rankings or model names; the tutoring exchange is a
constructed example (the same one used by Micro-Review) and the five-dimension reading
is labelled as illustrative, not a TutorBench score. Teachometry stays a text wordmark.

The full direction, design system and phased plan live in the project's plan doc.
