Evaluation dimensions评测维度

Five lenses for future evidence.未来证据的五个观察视角。

Each dimension defines a future trial-linked view of observable tutoring behavior. None is scored on this page today.

每个维度都定义了一个未来与评测记录关联的可观察教学行为视图。当前页面不会为任何维度评分。

  4. Adaptation适应能力Responsiveness to learner state对学生状态的响应
  5. Actionability可执行性Usability and follow-through可用性与后续执行
