Overview概览

TutorBench is provider-neutral measurement infrastructure for observable AI tutoring behavior. This page maps the public Teachometry surface to the repository contracts and guides that define setup, execution, artifacts, and interpretation.

TutorBench 是用于测量可观察 AI 教学行为、独立于服务提供方的基础设施。本页把 Teachometry 的公开页面映射到定义安装、执行、产物与解释方式的仓库契约和指南。

The website is a map into the repository’s existing contracts and guides. It does not replace the source documentation.

网站只是仓库既有契约与指南的入口地图，并不替代源文档。

Getting Started / Quickstart开始使用 / Quickstart

QuickstartQuickstart

Install the repository with Node 24, then run a deterministic local demonstration without provider credentials or network access.

使用 Node 24 安装仓库，然后在无需服务提供方凭据或网络访问的情况下运行确定性的本地演示。

Runtime requirement运行时要求Node 24>=24 <25

Current workflows use the Node 24 repository source. Published npm 0.1.0 requires Node 22 and includes Quickstart, but has no Tutor Health CLI or API. Check release channels and API boundaries 当前工作流使用 Node 24 的仓库源码。已发布 npm 0.1.0 要求 Node 22，包含 Quickstart，但没有 Tutor Health CLI 或 API。查看发行渠道与 API 边界

Repository main · Node 24

bash
git clone https://github.com/shuangyan123/tutorbench.git
cd tutorbench
npm ci
npm run quickstart

Published 0.1.0 · Node 22

bash
npm install tutor-benchmark@0.1.0
npx --no-install tutorbench quickstart

Provider-free, network-free, Judge-free. Quickstart uses four fixed development/smoke cases from tutor-eval-v0.1@0.1. It is not the canonical scoring cohort, produces no official benchmark score, and is not leaderboard eligible.无需服务提供方、无需网络、无需 Judge。Quickstart 使用来自以下数据集的四个固定开发/冒烟案例：tutor-eval-v0.1@0.1。它不是标准评分案例组，不会产生正式基准分数，也不具备排行榜资格。

Interpretation boundaries解释边界

Read the evidence carefully.请谨慎阅读证据。

These distinctions keep a useful development surface from making claims the repository does not support.

这些区分可以避免一个有用的开发页面做出仓库并不支持的主张。

Quickstart ≠ official benchmark scoreQuickstart ≠ 正式基准分数

It is a deterministic development/smoke demonstration, not calibrated benchmark evidence.

它是确定性的开发/冒烟演示，不是经过校准的基准证据。

Collection ≠ publication采集 ≠ 发布

Product Tutor and canonical model corpora remain preliminary unless publication requirements are met.

在满足发布要求之前，产品 Tutor 和标准模型语料都仍属于初步材料。

Judge ≠ ground truthJudge ≠ 参考真值

A Judge is an evaluator boundary. Unresolved criteria stay unresolved when required evidence is unavailable.

Judge 是一个评估器边界。当所需证据不可用时，未解决的标准必须继续保持未解决。

Human review ≠ automatic gold standard人工评审 ≠ 自动金标准

Human evidence can strengthen the method without becoming unquestionable ground truth.

人工证据可以增强方法，但不会自动成为不可质疑的参考真值。

Governance & contribution治理与贡献

Defined boundaries for an open repository.为开放仓库定义清晰边界。

Software, authored benchmark content, and the TutorBench name have deliberately separate scopes. Contributions can propose software, cases, rubrics, methodology, documentation, adapters, website changes, and calibration/audit infrastructure.

软件、人工编写的基准内容和 TutorBench 名称被刻意划分为不同范围。贡献可以涉及软件、案例、评分标准、方法论、文档、适配器、网站改动，以及校准/审计基础设施。

Community status: public participation information is available; public applications, reviewer intake, and a real Community Review campaign have not started.社区状态：公开参与说明已经可用；公开申请、reviewer intake 和真实 Community Review 活动尚未开始。
