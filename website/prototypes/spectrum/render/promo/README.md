# Promo film (Bilibili, 60 s) — final render

Direction A "会做题，不等于会教": a glass marble on a brass rolling-ball run. Approved animatic:
https://claude.ai/artifact/TWdrPJHPQyt2RGcPi5V61K

Files
- `o_open.py`, `a_marble.py` – Blender (bpy 5.2.3) scenes; `kit.py`, `tex.py` – shared helpers.
- `anim.py` – per-frame camera and object motion (kit.render calls it when `ANIM` is set).
- `comp.py` – subtitles, AI reply panel, five-question list, end card (layout in 1280×720 units, drawn at 1920×1080).
- `audio.flac` – the locked mix: sound effects (BigSoundBank CC0 + the user's Freesound clips) and the user's MiniMax track A.
- `render_final.py` – the whole pipeline, resumable.

Run (Windows, RTX GPU)

    python -m pip install pillow          # in the bpy 5.2.3 venv
    set DEVICE=OPTIX
    python render_final.py all            # fonts -> frames (1440 + end still) -> comp -> out/promo_1080p.mp4

Each step can be run alone (`fonts`, `frames`, `comp`, `mux`); finished frames are skipped, so an interrupted run just restarts.
`frames/`, `final/`, `fonts/`, `out/` are git-ignored.
